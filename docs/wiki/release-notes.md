# Release notes

## 1.0.2

- Supports Minecraft 1.21, 1.21.1, 26.1, 26.1.1, 26.1.2, and 26.2 on Fabric and NeoForge.
- Adds matching wood chests, trapped chests, and chest boats, including double-chest storage.
- Corrects chest item orientation and chest-boat rendering on Minecraft 1.21 and 1.21.1.

Install the JAR matching your Minecraft version and loader on both client and server. Architectury API is required on both loaders; Fabric also requires Fabric API.
